# Accounting documentation

Status: current architecture and operations entrypoint  
Last reviewed: 2026-08-25  
Upstream truth checked: `accounting-workflows@b7d2c3a379f966f4d69b56c2df113714a7051452`

This site explains how to operate, understand, and consume the accounting system. It does not own ledger data, accounting calculations, source documents, viewer implementation, or live runtime truth.

## Current backend spine

```text
canonical ledger ingest
  -> governed materialization / semantic + cash facts
  -> debt position/activity + treasury
  -> governed monthly frontier + annual dashboard
  -> publication bundle
  -> professional presentation + governed drilldowns
```

The current executable backend does **not** use a generic views stage, a parallel `metric_values` engine, or `accounting.human.*` as accounting authority. Older pages may still mention those concepts during the staged documentation migration; those references are not controlling current architecture.

## Repository boundaries

- `accounting-workflows`: canonical transformations, accounting rules, governed reporting calculations, publication generation, professional packs, and drilldowns.
- `accounting-viewer`: viewer-specific presentation over approved packaged outputs.
- `accounting-docs`: public operating guidance, architecture and contract explanation, and this Docusaurus site.

Accounting classifications documented here do not determine legal ownership, rights, enforceability, family governance, or negotiation positions.
